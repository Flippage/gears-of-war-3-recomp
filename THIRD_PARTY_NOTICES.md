# Third-party notices

This repository holds source code only. It contains **no game files** and **no third-party
binaries**: the ReXGlue SDK, the NVIDIA DLSS SDK and the AMD FidelityFX SDK are downloaded or built
on the user's machine by `scripts/build-sdk.ps1`, and nothing they produce is committed.

The release zips (`scripts/package.ps1`) contain our own binaries, the ReXGlue runtime DLLs built
from source without DLSS, AMD's FidelityFX DLLs (MIT, notice in `licenses\` inside the zip) and
the Microsoft Visual C++ runtime DLLs (redistributable). They contain no game files and nothing
from the NVIDIA DLSS SDK.

from, adapted from, or modify other projects; each keeps its original copyright and license.

## Community game patches

`tools/patch_game_patches.py` re-implements, as code in the generated C++, patches published in
[xenia-canary/game-patches](https://github.com/xenia-canary/game-patches)
(`patches/4D5308AB - Gears of War 3.patch.toml`). Only the patched addresses and the replacement
instructions are used (facts about the game executable), not that repository's files. Credit for
finding them goes to their authors:

- **illusion** and **boma**: Unlock FPS, Disable Lens Flares, Disable Ambient Occlusion, and the
  Gears of War 2 "Black Shading Fix" (located again in Gears of War 3 by this project).
- **boma**: Occlusion Query Fix, Disable Motion Blur, 16x Anisotropic Filtering, Resolution Scaling
  Fix / Disable All Post-Processing, Disable Depth of Field, Disable Bloom, Performance Patch
  Option B (Smart Shadow Cuts).
- **Sowa_95**: Performance Patch Option A (its dynamic-shadow site).

The texture streaming pool setting follows the Gears of War 2 port's `gow2_texture_streaming_fix`.

## NVIDIA DLSS SDK

Not included. `scripts/build-sdk.ps1` clones [NVIDIA/DLSS](https://github.com/NVIDIA/DLSS) on the
user's machine, links NGX into the locally built `rexgpu-xenos.dll` and copies `nvngx_dlss.dll`
next to the locally built game, for the user's own use under NVIDIA's DLSS SDK license. Nothing
from the DLSS SDK is committed, and the release zips are built without it (`-NoDlss`).

## AMD FidelityFX SDK

Not included. `scripts/build-sdk.ps1` fetches
[GPUOpen-LibrariesAndSDKs/FidelityFX-SDK](https://github.com/GPUOpen-LibrariesAndSDKs/FidelityFX-SDK)
v2.3.0 (API headers and AMD's signed binaries) on the user's machine, under AMD's licenses. Nothing
from it is committed.

  Visual Studio, Python: build tools.
